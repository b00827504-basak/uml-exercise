# UML Exercise

This project is for the UML exercise in my OOP course.

The exercise has two cases:
1. Hospital Management System
2. ABCD Records

## My approach

I first planned the UML diagrams on paper. Then I made digital diagrams and wrote simple Python examples based on the designs.

The Python files are small examples, not complete websites or real payment systems.

## Files

- `hospital_diagrams.md`: class and sequence diagrams for the hospital case.
- `abcd_diagrams.md`: use case, class, and sequence diagrams for ABCD Records.
- `hospital.py`: a simple hospital workflow example.
- `abcd_records.py`: a simple ordering example.
- `design_questions.md`: answers to the hospital design questions.

## Viewing the diagrams

Open the `.md` files on GitHub. The Mermaid diagrams should appear on the page.

## Running the code

You need Python 3. Run:

```bash
python3 hospital.py
python3 abcd_records.py
```

These programs only show example workflows. They do not process real patient data or real payments.
